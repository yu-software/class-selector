About the Project

Class selector is a web app that allow York University students to create a degree plan personalized for them, without the struggle and the stress of doing it yourself. We created a database with all the courses available and the information of the students. This connects with the availability of each course, to create a plan that allows the student to graduate in their desire date. We decided to do it this way because students want easy access and they do not like to download any other extra programs.

This project was motivated by our own experiences. We did not enjoy the process of selecting classes each semester. It is stressfull, messy, and even scary because we have limited resources and time because of our student visas. Also, talking with other students, we discovered that other students are not happy with the process either and have taken classes that they do not need or have tried to take classes when they are not available. This projects intends to help not only students but also advisors by making this process easier.

This project was created as project for our Software Development Class. However, we want to keep working on it to create something that is actually useful and used by the community. We want to create good documentation to leave the project in hands of future York University Computer Science students that would like to be part of it.
